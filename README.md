# La aventura matemática de Daniel

Práctica interactiva en español para tercer grado, organizada en 9 días.

## Sitio público

https://samofas2011-ux.github.io/practica-matematica-daniel/

El progreso se guarda únicamente en el navegador del dispositivo utilizado. El botón «Reiniciar toda la práctica» elimina ese progreso.

## Desarrollo y build

No necesita dependencias. Para preparar la publicación:

```sh
node build.mjs
```

El sitio generado queda en `dist/`. GitHub Pages publica la página estática desde la raíz de la rama `main` y realiza su build al recibir cambios.

## Prácticas para imprimir

La carpeta `imprimibles/` contiene una portada de Zelda con mapa de misiones y 14 páginas de ejercicios (112 ejercicios), las respuestas para la familia y una guía de uso con la cobertura del temario. Disponibles en https://samofas2011-ux.github.io/practica-matematica-daniel/imprimibles/ .
